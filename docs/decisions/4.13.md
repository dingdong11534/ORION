## 2. Design Token Adjustments (Contrast Verification)
- Automated WCAG 2.1 contrast check against Table 0 starting tokens showed all text pairs >= 4.5:1 and all habit hues >= 3.0:1.
- `border` (`#DAD4C7` light -> 1.42:1, `#3A3832` dark -> 1.33:1) failed the 3.0:1 requirement for control borders and chart strokes.
- **Adjustment:**
  - `hairline` remains `#E8E3D8` (light) / `#2F2D28` (dark) for subtle card/section dividers.
  - `border` (control borders & chart strokes) adjusted to **`#8F897D`** (light: 3.33:1 on surface, 3.14:1 on window) and **`#787368`** (dark: 3.29:1 on surface, 3.61:1 on window).

## 3. Architecture Decisions
- **Theme Singleton:** `Theme.qml` registered as `singleton Theme 1.0 Theme.qml` in `orion/ui/qml/components/qmldir`, supporting `light`, `dark`, and `system` (via `Qt.styleHints.colorScheme` in Qt 6.12), persisted in `SqliteSettingsStore`.
- **Charts & Visuals:** Drawn with a single `QQuickPaintedItem` or single `Canvas` per visual (zero per-cell QML objects; repaints only on data/size/theme change; zero looping animations -> idle CPU near zero).
- **Month Grid Grouping:** Weeks grouped in blocks of 7 starting from day 1 (week 5 holds remaining days), with 12% opacity habit-hue week band tints (week 5 reuses hue 1).
- **Habit Data:** Read-only `HabitStatsQuery` reusing `HabitService` and `zoneinfo` local dates.
- **Voice UI (4.12 Phase F) & Settings:** Integrated directly into the approved `ChatPage`, `Main.qml` navigation, and `SettingsPage.qml` using the shared `Theme` and components.
